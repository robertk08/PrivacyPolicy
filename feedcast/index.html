Subscriptions and Licensing

Feedcast offers an optional Premium subscription. In the App Store version of the Application, the subscription is sold and managed by Apple. To let you use Premium on the separate direct-download version of Feedcast (distributed outside the App Store), the Application sends the transaction identifier of your subscription to the Service Provider's licensing server at licenses.feedcast.org, which stores it in order to issue and refresh your license code. The direct-download version additionally sends a randomly generated device identifier together with that license code to the same server in order to activate Premium, enforce the limit of one active device per subscription, and let you deactivate a device. This information is used solely to provide this licensing functionality, is stored on the Service Provider's own servers (hosted on Cloudflare), is not used for advertising, and is not shared with data brokers.


Online Feeds

If you turn on the optional "Host Online" feature for a feed, the Application uploads that feed's listing (its title, episode details, and links) to the Service Provider's server at feeds.feedcast.org so it can be opened in other podcast apps. Your audio and video files are not uploaded; they stream directly from your own Mac. Turning the feature off removes the listing from the server.
